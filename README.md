# Minimal SPA Blog

This is a lightweight single-file SPA blog built with React + TypeScript + Tailwind CSS and Lucide icons.

Quick start:

1. Install deps:

```bash
npm install
```

2. Run dev server:

```bash
npm run dev
```

Admin credentials: `admin` / `secret123` (login via lock icon)

Data persistence: posts are saved to `localStorage` under `posts_v1`.
